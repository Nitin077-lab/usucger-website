USUCGER — restore the files Finder deleted
==========================================
DO NOT drag this into the folder in Finder — that is what deleted them.
Use Terminal instead; unzip merges into the folder without replacing it:

  unzip -o ~/Downloads/usucger-restore.zip -d ~/Documents/usucger
  cd ~/Documents/usucger
  git add -A
  git commit -m "Restore theme.css, brand assets and page sources"
  git push

Contains:
  assets/theme.css   colour theme, linked by every page
  assets/brand/      logo SVGs (the favicon comes from usucger-icon.svg)
  pages/             the source files build.py compiles the site from
