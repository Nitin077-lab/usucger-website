Software & Data

Directories, open-source packages, virtual laboratories and experimental databases for geotechnical teaching and research.

📂
Geotechnical & Geoenvironmental Software Directory (GGSD)
Catalogues more than 1,700 programs across geotechnical engineering, soil mechanics, rock mechanics, engineering geology, foundation engineering, hydrogeology, geoenvironmental and environmental engineering, data analysis and data visualisation. The best first stop when you need to know what exists for a given problem.
Browse the directory →
📈
geotech — Geotechnical Engineering Software Package in R
A free, open-source R package developed with USUCGER support. It performs phase-diagram and index parameter calculations, grain-size distributions, plasticity and soil classification, compaction, groundwater, subsurface stresses, Mohr circle analyses, consolidation settlement and rate, shear strength, bearing capacity, lateral earth pressures, slope stability and subsurface exploration.
Package on CRAN → Software information → Final report (PDF) → Presentation (PDF) →
🖥
Virtual Simulator for Advanced Geotechnical Laboratory Testing
A browser-based simulator that lets students set up and run advanced laboratory tests without tying up laboratory equipment — useful for pre-lab preparation, large sections and remote teaching.
Open the simulator →
📊
Case Western element test database
Over 234 tests conducted on three different sands in dense and loose conditions, plus the results of 18 tests on Edgar Plastic Kaolin clay and 8 tests on Hydrite 121 clay. Researchers can use the database to validate constitutive relations; it also makes an excellent source of real data for student projects.
Open the database →

The geotech R package came out of a USUCGER small research grant. Past funded projects and their deliverables are listed on the small research grants page.
